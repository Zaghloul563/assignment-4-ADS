# Assignment 4: String Processing

This C++ console program implements the Assignment 4 requirements:

- Load text from an external file.
- Enter text manually.
- Search with Boyer-Moore.
- Search with Rabin-Karp.
- Search for single or multiple comma-separated patterns.
- Detect overlapping matches.
- Highlight matches in the output.
- Print comparisons, match count, execution time, and algorithm name.
- Compare both algorithms on the same pattern.

## Build

```bash
make
```

## Run

```bash
./assignment4
```

## Test

```bash
make test
```
